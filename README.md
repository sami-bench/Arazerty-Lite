# Arazerty : Azerty B Darija! [LITE]

A simple and lightweight tool to type Arabic using an AZERTY keyboard layout. This project transcribes Latin characters into Arabic characters in real-time.

## Features
- **Real-time transcription**: Type on your AZERTY keyboard and see Arabic characters instantly.
- **Shortcuts**: Use specific key combinations for special Arabic characters (e.g., `kh` for `خ`).
- **Help Panel**: Includes a built-in keyboard mapping guide.
- **Copy to Clipboard**: Easily copy your converted text with a single click or `CTRL+C`.
- **Responsive Design**: Works well on small screens (400px width).

## How to use
1. Open `index.html` in your browser.
2. Start typing in the text area.
3. Use the "Help" button to see the keyboard mapping.
4. Click "Copy All" to copy the result.
